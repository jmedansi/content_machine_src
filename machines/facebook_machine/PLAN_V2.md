# Plan de Transformation Global : IncidenX Content Machine 2.0 🚀

Ce document définit la feuille de route complète pour transformer le dashboard actuel en une plateforme de création pilotée par l'intelligence visuelle et contextuelle.

## 🏗️ Phase 1 : Cœur du Système & Personas Dynamiques
- Finalisation des API pour la modification des Personas via le dashboard.
- Support du format Post "Trigger" (Post court + commentaire épinglé).

## 🎨 Phase 2 : Intelligence Visuelle (Moteur "Visual Analyzer")
- Nouveau module d'analyse inspiré des patterns GitHub (Fabric).
- **Règle Humaine Stricte** : Interdiction totale des objets abstraits, focus sur des scènes humaines réelles et professionnelles.

## 🧪 Phase 3 : Le Laboratoire de Contenu (Frontend)
- Renommage de l'onglet "Planning" en "Laboratoire 🧪".
- Nouveaux champs : Description contextuelle, objectifs, histoires.
- Bouton "Suggérer Image" pour obtenir une idée visuelle humaine parfaite en un clic.

## 🤖 Phase 4 : Automatisation & Publication
- Activation des réponses automatiques aux commentaires.
- Automatisation du commentaire d'accompagnement lors de la publication.
