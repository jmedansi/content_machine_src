# Exemples - Thread Maker

## Exemple 1 : How-To Thread

```
🧵 Comment j'ai généré 3M en 6 mois sans budget marketing :

(1/6) Constat :
Client paye pour résultats.
Pas pour processus.

Mon shift :
"J'utilise tel outil"
→ "J'ai généré X pour client"

(2/6)Étape 1 : Trouve 1 problème.
Pas 10.

Mon problème :
"PME Africa pas visibles en ligne"

(3/6) Étape 2 : Crée 1 solution.
Pas 5 options.

Ma solution :
Page Facebook + WhatsApp + 3 posts/semaine

(4/6) Étape 3 : Documente les résultats.
Chiffres vrais.

Ma doc :
- 127k reach/mois
- 34 demandes WhatsApp
- 23 closes

(5/6) Étape 4 : Partage en public.
Pas en privé.

Mon canal :
- LinkedIn
- Groupes Facebook entrepreneur

(6/6) Leçon :
Complexité est ton ennemi.
Simplicité + constance = résultats.

Suivre pour plus.
RT si utile.
```
