Voici le système complet de prospection à 8 agents :
1. Agent Scraper : Récupère les profils LinkedIn cibles selon vos filtres.
2. Agent Analyste : Visite le site web du prospect et note ses forces/faiblesses.
3. Agent Hook : Génère une accroche ultra-personnalisée basée sur son actualité.
4. Agent Copywriter : Rédige le corps du message en insérant la valeur unique.
5. Agent Relance : Planifie les rappels automatiques après 4 jours d'inactivité.
6. Agent Notificateur : Vous alerte sur Slack ou Telegram quand le prospect répond positivement.
